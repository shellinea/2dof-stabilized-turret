## 3. 图形界面使用详解

界面分四个区域：**端口设置**（顶）、**运动控制 / 驱动板使能**（左）、**原点回零 / 参数 / 系统状态**（右）、**提示**（底部日志）。

### 3.1 端口设置（顶部）

| 控件 | 默认 | 说明 |
|------|------|------|
| **链路** | `仿真` | `仿真`=不用硬件；`UART`=串口/TTL；`SLCAN`=CANable 适配器；`UDP`=CANBlaster 网桥 |
| **端口/地址** | `COM5` | UART/SLCAN 填串口号（如 `COM5`、`/dev/ttyUSB0`）；UDP 链路此栏忽略 |
| **波特率** | `115200` | 与电机固件一致（Emm_V5 常见 115200） |
| **电机地址** | `1` | 与电机内设地址一致，命令帧首字节 |
| **通讯校验方式** | `0x6B 固定` | 三选一，**必须与电机固件设置一致**（见 §5.2） |
| **连接 / 断开** | — | 点击切换；右侧标签由红「未连接」变绿「已连接」 |

### 3.2 驱动板使能

| 按钮 | 发送帧 | 作用 |
|------|--------|------|
| **使能驱动板** | `F3 AB 01 00` | 上电使能，电机可接受运动指令 |
| **关闭驱动板** | `F3 AB 00 00` | 断电释放 |

> 运动类按钮（位置/速度/回零）**必须先在使能状态下**执行，否则电机可能忽略或回「指令条件不符」。

### 3.3 运动控制

| 控件 | 说明 |
|------|------|
| **转速(RPM)** | 速度/位置指令的目标转速，16 位大端 |
| **加速度** | 0–255 档位，0=不使用加速度曲线 |
| **方向** | `cw` 顺时针 / `ccw` 逆时针 |
| **脉冲数** | 位置模式的脉冲数（32 位大端） |
| **绝对位置** | 勾选=绝对定位（`raF=01`），不勾=相对定位（`raF=00，相对当前位置`） |

| 按钮 | 发送帧 | 作用 |
|------|--------|------|
| **位置模式** | `FD …` | 按脉冲数定位 |
| **速度模式** | `F6 …` | 持续按转速旋转 |
| **立即停止** | `FE 98 00 00` | 立即停 |
| **清零位置角度** | `0A 6D` | 当前位置归零（不运动） |
| **多机同步运动** | `FF 66` | 触发所有已缓存指令同步执行 |
| **解除堵转保护** | `0E 52` | 清除堵转保护状态 |

### 3.4 原点回零

| 按钮 | 发送帧 | 作用 |
|------|--------|------|
| **设置单圈零点位置** | `93 88` | 把当前位置设为单圈零点 |
| **触发回零**（含「回零模式值」） | `9A hi lo` | 按指定模式启动回零，**电机将实际运动** |
| **强制退出回零** | `9C 48` | 中断并退出回零流程 |

### 3.5 参数读取

| 按钮 | 发送帧 | 作用 |
|------|--------|------|
| **读取系统状态** | `43 7A` | 返回并在「系统状态」面板显示位置/标志位 |
| **读取驱动参数** | `42 6C` | 读取驱动器配置 |
| **读取回零参数** | `AE 4B` | 读取回零相关参数 |

> 目前只有 **读取系统状态** 的应答会在右下面板结构化显示；其余读取命令的原始字节显示在底部「提示」日志里。

### 3.6 提示（底部日志）

每点一次按钮，都会打印：

```
-> Frame(01 F3 AB 01 00 6B)      ← 实际发出的字节
<- 01 F3 AB 02 6B                ← 收到的应答（若有）
   指令下发成功                   ← 状态码解读
```

这是判断「命令是否真的发出去」的最直接依据。

## 4. 命令行使用方法

### 4.1 通用参数（放在子命令**之前**）

```
--port COM5       串口端口
--baud 115200     波特率（默认 115200）
--slcan           使用 SLCAN 封装（CANable 适配器）
--udp             使用 CANBlaster UDP 网桥（组播 239.255.43.21）
--sim             仿真链路（无需硬件）
--addr 1          电机地址（默认 1）
--mode 6b|xor|crc8  校验方式（默认 6b）
-i                进入交互式会话
```

不给 `--port` / `--udp` 会自动回落到 `--sim` 并提示。

### 4.2 子命令一览

```bash
python zdt_tool.py --sim enable            # 使能驱动板
python zdt_tool.py --sim disable           # 关闭驱动板
python zdt_tool.py --sim stop              # 立即停止
python zdt_tool.py --sim clear             # 清零位置角度
python zdt_tool.py --sim sync              # 多机同步运动
python zdt_tool.py --sim status            # 读取系统状态
python zdt_tool.py --sim read-driver       # 读取驱动参数
python zdt_tool.py --sim read-homing       # 读取回零参数
python zdt_tool.py --sim set-zero          # 设置单圈零点位置
python zdt_tool.py --sim home              # 触发回零
python zdt_tool.py --sim exit-home         # 强制退出回零
python zdt_tool.py --sim release-stall     # 解除堵转保护
python zdt_tool.py --sim speed 300 --dir cw --acc 10        # 速度模式
python zdt_tool.py --sim move 32000 --abs --rpm 300         # 位置模式（绝对）
python zdt_tool.py --sim move 1600 --rpm 200                # 位置模式（相对，默认）
```

### 4.3 交互式会话

```bash
python zdt_tool.py --sim -i
```

进入后输入 `help` 看命令列表，`quit` / `q` 退出：

```
zdt> enable
zdt> move 32000 --abs
zdt> status
zdt> quit
```

### 4.4 真机示例

```bash
# UART / TTL
python zdt_tool.py --port COM5 enable
python zdt_tool.py --port COM5 move 32000 --abs --rpm 300

# 经 CANable 适配器（SLCAN）
python zdt_tool.py --port COM7 --slcan status

# 经 CANBlaster UDP 网桥
python zdt_tool.py --udp status
```

## 5. 连接真实电机的注意事项

### 5.1 接线与链路

* **UART/TTL**：上位机 TX→电机 RX，RX→电机 TX，**必须共地**。注意电平（多数模块 3.3V/5V TTL，勿直接接 RS-232 电平）。
* **SLCAN（CANable）**：需 CAN_H/CAN_L 双绞、两端 120Ω 终端电阻；波特率与 CAN 总线一致。
* **CANBlaster（UDP）**：需同一网段/组播可达；组播地址 `239.255.43.21`（从二进制还原）。

### 5.2 校验方式必须与电机一致（最容易出错）

电机固件内部设了「通讯校验方式」，上位机必须**选同一个**：

| 界面选项 | CLI `--mode` | 算法 |
|----------|--------------|------|
| `0x6B 固定` | `6b` | 恒定字节 `0x6B`（出厂默认） |
| `XOR 异或` | `xor` | 逐字节异或 |
| `CRC8` | `crc8` | CRC-8/MAXIM（多项式 0x31） |

选错会出现「返回数据错误 / 指令格式错误」或**电机无任何应答**。若不确定，先用默认 `0x6B`。

### 5.3 电机地址

* 命令帧首字节是电机地址，**必须与电机内设地址相同**（默认 `1`），否则电机不响应。

### 5.4 运动指令的前置条件（安全）

* **先使能**：`enable` 后再发 `move` / `speed` / `home`，否则可能被拒（状态码 `0x9F 指令条件不符`）。
* **方向与脉冲含义**：脉冲数对应电机细分/编码器，先小量试（如 1000 脉冲）确认方向与行程。
* **回零会真实运动**：`触发回零` 会让电机自动寻找原点，务必确认机械行程安全。
* **`立即停止` / `强制退出回零`** 是异常时的急停手段。
* **堵转**：遇堵转会触发保护，解除用 `release-stall`。

### 5.5 绝对 / 相对

* **位置模式**勾选「绝对位置」→ 目标是绝对脉冲位置（`raF=01`）。
* 不勾 → 相对当前位置走 `脉冲数`（`raF=00`）。**切换前先 `读取系统状态` 确认当前位置**，避免超程。

## 6. 已知限制与免责说明

1. **这是「行为复现」，不是厂商原始源码。**
   从加壳 GUI 二进制无法逐字还原 C++ 源码；本程序还原的是**可观测行为与线缆协议**，能真正驱动电机。

2. **系统状态应答的字段偏移是推断的。**
   `zdt_tool.py::decode_status` 的字节切分依据 UI 展示的字段名（编码器线性值 / 目标位置角度 / 实时位置角度 / 位置角度误差 / 各标志位）推断，是**唯一未逐字节比对二进制**的部分。若真机返回的字段值不对，以此为准调整偏移即可。

3. **CandleApi（WinUSB 直连）未实现。**
   原程序支持它（导入 `candle`），本复现提供 UART / SLCAN / UDP 三条链路。

4. **本工具内部还有第二套「寄存器方言」协议**（形如 `addr 10 00 9A 00 …`，11 字节帧），用于另一类电机固件；本复现实现的是 **Emm_V5 方言**。

5. **风险自担。** 真机操作涉及机械运动，请在断电/空载条件下先验证，确认无误再带载运行。

## 7. 常见问题（排错）

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 双击 `.bat` 闪退 | 未装 Python 或未加入 PATH | 命令行 `python --version` 检查；重装 Python 勾选 "Add to PATH" |
| 点连接报 `pyserial not installed` | 未装 pyserial | `pip install pyserial`，或改用「仿真」 |
| 连接失败 `could not open port` | 串口号错 / 被占用 | 设备管理器确认 COM 号；关闭占用该口的软件 |
| 电机无任何应答 | 地址错 / 校验错 / 接线错 | 核对 §5.2 §5.3 §5.1；先 `status` 试探 |
| 返回「指令格式错误」 | 校验方式不匹配 | 换成与电机一致的 `--mode` |
| 返回「指令条件不符」 | 未使能 / 未回零等前置条件未满足 | 先 `enable` |
| 界面中文乱码 | 终端编码非 UTF-8 | `.bat` 已含 `chcp 65001`；命令行手动 `chcp 65001` |
| `status` 字段值明显不对 | 应答偏移为推断值（见 §6.2） | 以真机手册/实测为准调整 `decode_status` |
