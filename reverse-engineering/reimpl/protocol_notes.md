# ZDT Emm_V5 协议速查（自二进制还原）

> 本文只记录**从 `CAN.exe` 逆向得到**的线缆层细节。
> 通用 Emm_V5 指令含义可查厂商手册；这里给的是**本程序实际使用**的格式与校验。

## 1. 帧结构

```
+--------+---------------------+-----------+
| addr   | payload             | checksum  |
| 1 byte | 1..11 bytes         | 1..2 bytes|
+--------+---------------------+-----------+
```

* `addr`：电机地址（本程序配置项 `canAddr`，UI「电机地址」）。
* `checksum`：默认单字节 `0x6B`，可选 XOR / CRC-8（见 §3）。

## 2. 指令负载（按 payload 首字节分类）

| payload (hex) | 功能 | 备注 |
|---------------|------|------|
| `F3 AB <on> <sync>` | 使能/关闭驱动板 | `on`=01 使能, 00 关闭 |
| `F6 <dir> <spdH> <spdL> <acc> <sync>` | 速度模式 | 转速大端 16 位 (RPM) |
| `FD <dir> <spdH> <spdL> <acc> <p3><p2><p1><p0> <raF> <sync>` | 位置模式 | 脉冲大端 32 位；`raF`=00 相对, 01 绝对 |
| `FE 98 00 <sync>` | 立即停止 | |
| `FF 66` | 多机同步运动 | |
| `0A 6D` | 清零位置角度 | |
| `43 7A` | 读取系统状态 | 返回状态帧，见 §4 |
| `42 6C` | 读取驱动参数 | |
| `AE 4B` | 读取回零参数 | |
| `93 88` | 设置单圈回零零点位置 | |
| `9A 00` | 触发回零 | |
| `9C 48` | 强制中断并退出回零 | |
| `0E 52` | 解除堵转保护 | |

`dir`：00=CW, 01=CCW。
`sync`：00=单机, 01=多机同步标志。

## 3. 校验算法（三种模式）

从二进制校验分发器 **0x407900** 及内联代码还原；对应 `enum CheckMode`。

### 3.1 `CHECK_6B`（默认）
校验字节恒为 `0x6B`。

### 3.2 `CheckXOR`
```
chk = XOR( addr, payload[0..n] )        # 内联于 0x4079B3
```

### 3.3 `CheckCRC8` = CRC-8/MAXIM
* 多项式 `0x31`（反射 `0x8C`），初值 `0x00`，反射算法。
* 查表位于 **0x452A80**，前 16 字节：
  `00 5E BC E2 61 3F DD 83 C2 9C 7E 20 A3 FD 1F 41`
* 自检向量：`crc8_maxim("123456789") == 0xA1`。

### 3.4 `modbus_calCRC` = MODBUS CRC-16
* 多项式 `0xA001`（反射 `0x8005`），初值 `0xFFFF`。
* 分高低字节两张表：**0x452880**（高）/ **0x452980**（低）。
  `0x452980` 前 8 字节：`00 C1 81 40 01 C0 80 41`
* 自检向量：`modbus_crc16("123456789") == 0x4B37`。

## 4. 系统状态应答（`43 7A` 的返回）

UI 展示了以下字段（中文标签来自程序字符串表）：

```
编码器线性值 / 目标位置角度 / 实时位置角度 / 位置角度误差
正在回零标志 / 回零失败标志 / 使能状态标志 / 电机到位标志
电机堵转标志 / 堵转保护标志
```

`zdt_tool.py::decode_status` 的字节偏移按上述字段顺序推断，为唯一未逐字节比对的部分。

## 5. 传输层

| 方式 | 识别特征 | 实现 |
|------|----------|------|
| **UART/TTL** | `QSerialPort` | 直接发 §1 帧；`zdt_tool.py --port` |
| **SLCAN** | `CANable 1.0/2.0 detected`, `SLCANInterface` | ASCII `t<ID><DLC><DATA>\r`；`--slcan` |
| **CandleApi** | 导入 `candle` | WinUSB 直连 (本复现未实现) |
| **CANBlaster** | `QUdpSocket` + 组播 `239.255.43.21` | UDP 报文；`--udp` |

SLCAN 帧示例（清零位置，地址 1）：
```
t0014010A6D6B\r
```
`t`=标准帧, `001`=CAN ID, `4`=DLC, `010A6D6B`=数据。
