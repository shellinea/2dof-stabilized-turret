## 1. 系统连接与先决条件

### 1.1 总线拓扑

```
   PC 上位机
      │ USB
 ┌────┴─────────┐
 │  USB转CAN    │   (ZDT_CANable，上位机里叫 candle0)
 │  CANable     │
 └──┬────────┬──┘
    │CAN_H   │CAN_L
    │        │
 ═══╪════════╪═══════════════  CAN 总线（两端各 120Ω 终端电阻）
    │        │
 ┌──┴──┐  ┌──┴──┐
 │电机1 │  │电机2 │           独立供电 10–29V（≥3A），与 CAN 共地
 │Addr1 │  │Addr2 │
 └─────┘  └─────┘
```

### 1.2 接线三条铁律

| 铁律 | 说明 | 出错后果 |
|---|---|---|
| **H 接 H、L 接 L** | 电机端 `R/A/H → CAN_H`、`T/B/L → CAN_L` | 接反 → 完全不通 |
| **两个电机地址不能重复** | 出厂默认都是 1，必须改成 1 和 2 | 一起应答 → 总线冲突 → 没有数据返回 |
| **必须有 120Ω 终端电阻** | 总线最两端各一个（H-L 之间） | 500k 下丢帧/偶然能通 |

**另外两个容易忽略的点**：
- **共地**：USB 转 CAN 是 USB 供电、电机是 24V 供电，两边地要接在一起，否则常常通信不稳定。
- **供电要够**：电机 V+ 需要 10–29V、≥3A。**USB 转 CAN 不给电机供电。**

### 1.3 上机前的"软件先决条件"

电机里有一个参数 **`P_Serial`（通讯端口复用）**，出厂默认是 **`UART`**。
**CAN 通信必须把它改成 `CAN1-MAP`**，否则怎么接都不通。

- 改的方法（通信没通时只能这样）：**电机板载小屏 + 按键**。
- 操作：长按 `Enter` 3 秒进菜单 → `Next` 翻到 `P_Serial` → `Enter` → 选 `CAN1-MAP` → `Enter` 确认 → 长按 `Next` 1 秒退出。

> **小屏在板子正中间**（OLED，黑底白字，正常显示 `0.0° / 0.00err / 0clk`）；
> **两个按键在板子下边缘**，丝印 `Next` / `Enter`。手册第 12 页有标注图。

## 2. CAN 通信原理

看不懂这一章也能用上位机，但看懂之后你就知道每个按钮在发什么。

### 2.1 一帧 CAN 报文的组成

电机用的是 **CAN 扩展帧**，格式固定：

```
┌──────────────┬───────────┬──────────────┬─────────┐
│  扩展帧 ID    │  功能码    │   命令数据     │  校验码  │
│ (Addr<<8)|Packet │  Code   │   0 ~ 7 字节   │ 0x6B    │
└──────────────┴───────────┴──────────────┴─────────┘
```

- **扩展帧 ID = `(Addr << 8) | Packet`**
  - `Addr`：电机地址（1、2…；0 = 广播）
  - `Packet`：第几包数据，从 0 开始（命令 ≤8 字节时恒为 0）
- **数据内容**：第 1 个字节是功能码，后面是参数
- **校验码**：Emm 固件默认固定 `0x6B`

### 2.2 举例（这是理解一切的关键）

**发送"读取实时位置"给地址 1：**
- 扩展帧 ID = `(1<<8)|0` = `0x0100`
- 数据 = `36 6B`（`36` 是功能码，`6B` 是校验码）
- 电机返回：ID `0x0100`，数据 = `36 符号 位置4字节 6B`

**发送"位置模式"（13 字节，超过 8 字节，要分包）：**
```
完整命令：01 FD 01 0F A0 00 00 01 FA 00 00 00 6B
    第 0 包 → ID = 0x0100，数据 = FD 01 0F A0 00 00 01 FA
    第 1 包 → ID = 0x0101，数据 = FD 00 00 00 6B
```
> 这是 CAN 通信最需要建立的概念：CAN 一帧最多 8 字节数据，长命令必须拆包，
> 靠 ID 低 8 位的 Packet 序号把包拼回去。粘包/丢包就会导致命令失效，
> 所以手册强调"每条命令之间要延时几毫秒"。

### 2.3 电机的返回码含义

| 返回码 | 含义 |
|---|---|
| `02` | 收到命令，执行正确 |
| `12` | 触发回零时，当前已在零点/限位已触发，电机不动 |
| `9F` | 动作完成（到位 `FD 9F`、回零完成 `9A 9F`、夹紧 `F5 9F`） |
| `E2` | 参数错误（范围不对 / 条件不满足，如低压、堵转保护中） |
| `EE` | 命令格式错误 |

### 2.4 广播与同步

- **广播地址 0**：`00 FF 66 6B` 就是全局"触发多机同步运动"。
- **同步标志（snF）**：命令里那一位设为 `1` 时，电机只**缓存**命令不执行；
  所有电机都缓存好后，发一次广播 `00 FF 66 6B`，它们**同时开始运动**。
  这正是云台两个电机必须一起动时用的机制。

## 3. 上机操作流程

下面每一步都给出 **①上位机点哪里 ②底下等效的 CAN 命令 ③你应该看到什么**（理论现象）。

### 步骤 0：给两个电机分配不同地址

并联前先做这一步，否则一定"没有数据返回"。

- **方法 A（推荐，通信通的情况下）**：只连一个电机 → 上位机"修改驱动ID地址" → 填 ID=1 → "写入并保存ID地址"；
  换成另一个电机 → 改成 ID=2。
  - 等效命令（把当前电机改成地址 2）：`01 AE 4B 01 02 6B`
- **方法 B（通信还不通）**：用板载小屏菜单改 `ID_Addr`。

> **理论现象**：写地址后电机返回 `01 AE 02 6B`；之后再发地址 2 的命令才有回应。

### 步骤 1：连接 CAN

上位机左上角 **CAN端口设置**：

| 项 | 值 | 说明 |
|---|---|---|
| 端口 | `candle0` | USB 转 CAN 识别出的设备 |
| CAN速率 | `500000` | 必须和电机 `CAN_Baud` 一致（默认 500K） |
| 电机地址 | `1` | 先操作 1 号，之后切到 2 |
| 校验字节 | `0x6B` | 和电机 `Checksum` 一致 |

点 **"连接CAN"**（连上后按钮变成"关闭CAN"）。

> **理论现象**：按钮文字变为"关闭CAN"= 总线已打开。若报错，多半是驱动/端口问题。

### 步骤 2：读取系统状态 —— 验证通信是否真的通了

点 **"读取系统状态参数"**。

- 等效命令：`01 43 7A 6B`
- 返回一大串（31 字节），上位机会自动解算并填到左侧各栏。

> **理论现象**：左侧"总线电压 / 相电流 / 目标位置角度 / 实时位置角度 / 位置角度误差…"全部出现数值。
> - **这是排障第一现场**：如果这里显示"没有数据返回"，先别继续，去[第 5 章](#5-常见问题排查)。
> - 先看"总线电压"是否在 10–29V。

### 步骤 3：使能驱动板

点 **"使能驱动板"**。

- 等效命令：`01 F3 AB 01 00 6B`（末尾 `01`=使能；改 `00` 即失能松轴）

> **理论现象**：使能后**轴被锁死，用手拧不动**；点"关闭驱动板"后**轴能拧动**。
> 这是判断"电机到底有没有被驱动"最直观的现象。

### 步骤 4：速度模式 —— 让电机转起来

在 **运动控制 → 速度模式** 里设：

| 项 | 示例 | 说明 |
|---|---|---|
| 方向 | CW / CCW | 正反转 |
| 速度 | 20 | 单位 RPM，范围 0–3000 |
| 加速度 | 0 | **0 = 直接启停**；非 0 = 曲线加减速（见 4.2） |

点 **"发送指令"**。

- 等效命令：`01 F6 方向 速度H 速度L 加速度 同步 6B`
  例：`01 F6 01 05 DC 0A 00 6B` = CCW、1500RPM、加速度档 10

> **理论现象**：
>
> - 加速度=0 时电机**"嗡"一下就窜到设定转速**；加速度越大，加速越猛。
> - 想停：点 **"触发立即停止指令"**（`01 FE 98 00 6B`），或发速度 0。
> - **安全习惯**：第一次试转先用低转速（如 20–100RPM）。
> - 反转只需把"方向"改一下（CW↔CCW），**别用负数速度**。

### 步骤 5：位置模式 —— 走精确角度

在 **运动控制 → 位置模式** 里设方向、速度、加速度、**脉冲数**、**相对/绝对标志**，点"发送指令"。

- 等效命令（13 字节，CAN 上分包为两条）：
  `01 FD 方向 速度H 速度L 加速度 脉冲4字节 运动模式 同步 6B`
- **运动模式**：`00`=相对上一目标位置、`01`=相对坐标零点(绝对)、`02`=相对当前位置

**脉冲 ↔ 角度换算**（默认 1.8° 电机、16 细分）：

```
1 圈 360° = 3200 脉冲  →  1 脉冲 = 0.1125°
脉冲数 = 角度(°) × 3200 ÷ 360 = 角度 × 8.889
```
| 想转 | 脉冲数 |
|---|---|
| 90° | 800 |
| 180° | 1600 |
| 360°（1 圈） | 3200 |

> **理论现象**：电机按设定速度走完指定角度**精确停住**，位置由闭环编码器保证，不丢步。
>
> - 配合"读取系统状态参数"看 **实时位置角度** 是否等于目标角度、**位置角度误差**是否趋近 0。
> - **相对 vs 绝对**：相对是"从当前位置再走这么多"，绝对是"走到坐标零点算起的某个角度"。

### 步骤 6：回零（建立坐标系）

云台必须先有"零点"才有意义。流程（单圈就近回零为例）：

1. 手动把电机轴拧到你想当作 0° 的位置；
2. 点 **"设置单圈回零的零点位置"**（勾选"是否存储"）→ 等效命令 `01 93 88 01 6B`；
3. 在 **原点回零** 面板设回零模式/方向/速度，点 **"修改回零参数"**；
4. 以后随时点 **"触发回零"** → 等效命令 `01 9A 回零模式 同步 6B`
   （`00`单圈就近 / `01`单圈方向 / `02`无限位碰撞 / `03`限位 / `04`回绝对零点 / `05`回掉电位置）。

> **理论现象**：
> - 就近回零：电机**朝最近的零点方向**回去并停住。
>   - 无限位碰撞回零：电机一直转，**撞到结构边缘"顶"一下**当作零点（靠"转速骤降 + 电流骤升 + 持续时间"三个条件判断）。
> - 已在零点时触发，返回 `12`，电机不动。
> - 回零中途想停 → 点 **"强制中断并退出回零操作"**（`01 9C 48 6B`）。

### 步骤 7：双电机同步运动（云台的关键）

两个电机必须**同时开始**才不会让托盘扭曲/齿轮打架。上位机用**多机同步标志 + 广播触发**：

1. **地址=1** → 位置模式设参数，把 **"多机同步标志"设为 `True`** → 发送指令
   （等效：`01 FD …(同步标志=01)… 6B`，此时电机只缓存不动）
2. **地址=2** → 同样设参数、同步标志 `True` → 发送指令
   （等效：`02 FD …(同步标志=01)… 6B`，同样只缓存）
3. 点 **"触发多机同步运动"** → 广播 `00 FF 66 6B`

> **理论现象**：第 1、2 步发完后**两个电机都静止不动**（只在缓存）；
> 点下广播触发的**那一瞬间两个电机同时启动**。
>
> - 两条命令之间记得留几毫秒间隔，防止粘包。

### 步骤 8：把它变成云台运动（差速解算）

本云台两个电机通过 1:1 齿轮驱动同一个托盘（传动比 i=1），运动学关系：

```
pan  (托盘自转) = (θ1 - θ2) / 2
tilt (托盘俯仰) = (θ1 + θ2) / 2
```

| 想要的动作 | 怎么发命令 |
|---|---|
| 只**俯仰**（抬头/低头） | 两电机**同向、同角度**：θ1 = θ2 = a |
| 只**自转**（左右转） | 两电机**反向、同角度**：θ1 = +a，θ2 = −a |

> **理论现象**：同向 → 托盘绕连接轴承**俯仰**；反向 → 托盘**水平自转**。
> 两个动作在电机空间是**耦合**的（对应 θ1+θ2 与 θ1−θ2），所以任意单个动作都要两个电机配合。

## 4. 参数含义与理论现象

### 4.1 速度 / 脉冲 / 细分

- 速度单位 **RPM**（转/分），范围 0–3000。
- 细分默认 **16**，1.8°电机 → **3200 脉冲/圈**。
- Emm 固件下若要 0.1RPM 精度，可开启速度值缩小 10 倍输入。

### 4.2 加速度（最容易踩坑的参数）

公式：每隔 `(256 - acc) × 50us` 变化 1RPM（acc 为加速度档 0–255）。

| 加速度值 | 行为 |
|---|---|
| **0** | 不使用曲线，**直接启动/直接停**（冲击大，易堵转） |
| 非 0 | 曲线加减速，**值越大越快**。例：acc=100 → 每 7800us 加/减 1RPM |

> **现象对照**：acc=0 直接窜速；acc 越小，起停越"软"、曲线越长。

### 4.3 位置模式的三个运动模式

| 值 | 含义 |
|---|---|
| `00` | 相对**上一目标位置**运动 |
| `01` | 相对**坐标零点**的绝对运动 |
| `02` | 相对**当前实时位置**运动 |

### 4.4 PID（Emm 固件）

- 读取：`01 21 83 6B`；修改：`01 4A C3 是否存储 Kp4 Ki4 Kd4 6B`
- 上位机右下角 **修改PID参数** 里的 Kp / Ki / Kd，默认 **18000 / 10 / 18000**。
- **Kp（比例）**：越大越"硬"、跟随越快，过大会震荡/啸叫。
- **Ki（积分）**：消除稳态误差，过大易过冲。
- **Kd（微分）**：抑制震荡、增加阻尼，过大易抖。
- **调参顺序**：先只调 Kp 到"刚不震荡"，再加一点 Ki 消余差，最后加 Kd 压震荡。改完勾"是否存储"。

### 4.5 几个和"动作完成"有关的参数

- **位置到达窗口**：默认 0.8°。误差小于它就算"到位"。
- **控制命令应答**：`Receive`（默认，只回"收到"）/ `Reached`（到位才回）/ `Both` 等。
  想让电机到位主动上报，就设成 `Reached`/`Both`，会收到 `地址 + FD/9A + 9F + 6B`。
- **堵转保护**：默认开启。触发后电机会**松轴保护**，小屏显示 `Clogging Protect!`，
  解除方法：点 **"解除堵转保护"**（`01 0E 52 6B`）或连按两下 Enter。

## 5. 常见问题排查

### 5.1 "没有数据返回"（我在这个项目里踩过的坑，按顺序查）

| 序号 | 原因 | 现象 | 处理 |
|---|---|---|---|
| 1 | **两个电机地址都是 1** | 一起应答→总线冲突 | **先只接一个电机**测；再把地址改成 1 和 2（见步骤 0） |
| 2 | **接线松动 / 接触不良**（杜邦线、端子、排线） | 完全无返回，或时通时不通 | 逐个**重插压紧**接头（尤其 H/L、GND、V+）；万用表通断档核对；**先用杜邦线直连电机，绕开分线板** |
| 3 | **`P_Serial` 不是 `CAN1-MAP`** | 完全无返回 | 板载小屏菜单改成 `CAN1-MAP`（见 1.3） |
| 4 | **CAN_H / CAN_L 接反** | 完全无返回 | 对调 H/L 两根线 |
| 5 | **没共地 / 缺 120Ω** | 时通时不通/不稳 | 共地 + 总线两端加 120Ω（ZDT 官方例程要求） |
| 6 | **电机卡在固件升级(bootloader)模式** | **小屏不显示 + 蓝灯常亮** | 断电重上电；不行就用 `6. 固件更新教程/Y42_IAP_251112.exe` 重刷固件 |
| 7 | **电机没供电** | 小屏不亮 | 查 V+ 有没有 10–29V、≥3A，极性有没有接反 |

> ⚠️ **第 6 条必须重点记**：只要"**屏幕不显示 + 蓝灯常亮**"，就是电机没在跑应用固件（停在 bootloader），
> 此时**既不显示、也不回 CAN 数据、电机也不动**——所有参数排查都是白费，先重刷固件。
> 正常状态是**绿灯亮、小屏显示角度**。
>
> 📌 **本项目实际踩坑记录（2026-09）**：最终排查出的根因是 **① 固件卡在 bootloader（重刷解决）+ ② 接线松动/接触不良（重新压紧解决）**。
> 所以遇到"单电机也没数据"时，**先重刷一次固件、再检查每个接头是否插紧**，往往比查参数更快。

### 5.2 能读取参数，但电机不转

- 没**使能** → 点"使能驱动板"，确认轴锁住。
- 触发了**堵转/过热/过流/低压保护** → 看小屏提示，点"解除堵转保护"。
- 速度/脉冲数为 0，或加速度=0 时速度设得太高导致堵转。
- 方向搞反 / 相对绝对模式选错，电机"动了但看不出来"。

### 5.3 通信偶发失败 / 抖动

- 缺 120Ω 终端电阻，或 H/L 走线太长、和动力线捆在一起 → 加终端电阻、信号线远离动力线。
- 两条连续命令之间**要留延时**（几 ms），防止 CAN 粘包。

## 7. 上手最短路径（TL;DR）

1. 只接 **1 个**电机，`P_Serial` 改 `CAN1-MAP`，H↔H、L↔L、共地、加 120Ω、供 24V。
2. 上位机连 CAN（candle0 / 500000 / 地址1 / 0x6B），点"读取系统状态参数"→ 有数就成功一半。
3. 点"使能驱动板"→ 轴锁死；"速度模式"低速试转 → 转向对；"位置模式"走 90° → 角度准。
4. 改地址为 2，接第二个电机，重复验证。
5. 两个电机一起：位置模式勾"多机同步标志"→ 都发送 → 点"触发多机同步运动" → 同时动。
6. 回零建坐标系，然后按 `θ1±θ2 → pan/tilt` 把云台动起来。
